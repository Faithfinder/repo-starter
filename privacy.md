# Privacy policy: Repo Starter: Templates for Bitbucket

_Last updated: {{ site.updated }}._

**Who we are.** Repo Starter: Templates for Bitbucket ("the app") is made by {{ site.vendor }}, {{ site.location }}. Contact: [{{ site.support_email }}](mailto:{{ site.support_email }}).

**What the app stores.** Only the template settings that repository admins enter: the template repository's Bitbucket ID, the template name and description, the extra branch names to create, and whether to copy repository details and Pipelines settings. The app stores no personal data: no account IDs, names, email addresses or repository contents.

**What the app reads but does not store.** When someone creates a repository from a template, or applies one, the app reads, as that user, the template's files, branches, repository details, Pipelines settings and variables, and webhook list. It uses them to set up the new repository and then discards them. Values of secured variables and webhook secrets can't be read by apps and are never seen.

**Where data lives.** Everything stays on Atlassian's infrastructure (Forge hosted storage and compute). The app is eligible for Atlassian's "Runs on Atlassian" program: it sends no data outside Atlassian.

**Sharing.** We don't sell or share data, and we don't use third-party analytics.

**Retention and deletion.** Template settings are kept while the app is installed. Repository admins can remove a template at any time with **Stop using as template**. Entries for deleted repositories are removed the next time the workspace's template list is opened. When you uninstall the app, Atlassian deletes its Forge storage under Atlassian's data-retention policy.

**Logs.** If an operation fails, the app may write an error message to Atlassian's Forge logs. These logs don't contain file contents and are kept by Atlassian under its retention policy.

**Your rights.** Because the app stores no personal data, there's usually nothing to access or delete about an individual. Send any privacy question to [{{ site.support_email }}](mailto:{{ site.support_email }}).

**Changes.** We'll post updates here and change the date above.
