# Repo Starter: Templates for Bitbucket

Create Bitbucket Cloud repositories from templates, with files, branches and settings copied in one go.

Mark any repository as a template. Anyone who can read it can then create a new repository from it in a couple of clicks: all of its files as one fresh commit (binaries, executable scripts and symlinks included), the branches you choose, the repository details and the Pipelines settings. A clear report says what was copied and what, like webhooks or secured variables, you need to finish by hand.

Runs on Atlassian and never stores your code. **Free while in beta.**
